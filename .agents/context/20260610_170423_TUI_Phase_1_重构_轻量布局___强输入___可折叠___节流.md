# TUI Phase 1 重构计划（v2 — 安全加固版）

> Created: 2026-06-10 17:04:23 | Updated: 2026-06-10 17:15

## 目标
将 mofox-code TUI 从"调试日志终端"升级为适合长时间 coding agent 使用的工作界面，不改 WebSocket 协议和后端交互。

## 优先级分级

| 优先级 | 改动 |
|--------|------|
| **P0** | Ctrl+C 智能中断、审批/rollback 不丢草稿、移除 pause()+input()、多行输入(Alt+Enter/Ctrl+J)、Stream 节流且不重复 final emit |
| **P1** | 轻量状态栏+去Frame、输入历史+Tab补全、thinking结束后折叠、bash长输出保守折叠 |
| **P2** | checkpoint数/文件变更数/右侧activity等产品化信息（本期不做） |

## 涉及文件
- `src/mofox_code/tui/layout_manager.py` — 布局、输入(Ctrl+J/Alt+Enter)、Ctrl+C、draft 管理、历史记录
- `src/mofox_code/tui/app.py` — 审批/rollback草稿保存、thinking折叠时机、Ctrl+C分流、`_refresh_header()`
- `src/mofox_code/tui/stream_renderer.py` — 流式渲染节流 + `_last_emitted_content` 去重
- `src/mofox_code/tui/renderer.py` — `build_thinking_collapsed()`、bash保守折叠
- `src/mofox_code/tui/input_handler.py` — `CommandCompleter` Tab补全
- `tests/test_stream_renderer.py` — 追加行为测试（**不新建测试结构**）
- `pyproject.toml` — 添加 pytest 配置和 dev 依赖

## 补充约束（关键！实现时必须遵循）

1. **不使用 Shift+Enter 作为唯一换行方式**。prompt_toolkit 不保证支持 `s-enter`。改为 `Alt+Enter`（escape+enter）和 `Ctrl+J` 换行，`Enter` 发送。
2. **Buffer 挂 InMemoryHistory 后**，Enter accept 时必须调用 `append_to_history()`，否则历史可能不记录。`Buffer` 初始化加 `multiline=True`。
3. **审批草稿只在审批队列从空→非空时保存一次**，所有审批处理完后恢复一次；不要每个 approval request 都 push/pop draft。
4. **/rollback 选择也视为临时输入模式**，不能 `clear_buffer=True` 直接清空用户正在编辑的输入。复用草稿保存机制。
5. **Thinking 折叠时机要补全**：不只放在 `_close_active_response_segment()`，还要覆盖 `agent.text final`、`agent.status ready`、tool.call/source切换 等路径。提取为专门的 `_collapse_active_thinking_if_needed()` 方法。
6. **bash.output 不得默认 exit_code=0**。没有 exit_code 时只能做保守折叠（仅对超长 stdout 截断），不能判断为成功。stderr 默认不折叠。
7. **StreamMarkdownRenderer.finalize() 必须避免重复 emit**：用 `_last_emitted_content` 去重。第一块内容**立即渲染**不等 50ms。
8. **状态栏 checkpoint 数通过 `TUIApp._refresh_header()` 统一刷新**，避免各事件处理器散落 build_header 调用。
9. **当前已有 `tests/test_stream_renderer.py`（22 passed）**，追加测试即可，不新建测试结构。`pyproject.toml` 增加 pytest pythonpath 配置。

## 一、布局重构：去掉三层 Frame → 轻量状态栏 + 主体 + Composer

### 现状
```text
┌ Status ───────────────┐  ← Frame(title="Status")
│ MoFox Code │ ...      │
└───────────────────────┘
┌ Conversation ─────────┐  ← Frame(title="Conversation")
│ (body items...)       │     wrap_lines=False
└───────────────────────┘
┌ Input ────────────────┐  ← Frame(title="Input", height=4)
│ footer hint           │
│ > _                   │     输入框 1 行
└───────────────────────┘
```

### 目标结构
```text
 MoFox Code  ● coding  Neo-MoFox  auto-review OFF  +3 -1   ← 单行状态栏（无 Frame）
──────────────────────────────────────────────────────────
 (body 消息流)
──────────────────────────────────────────────────────────
 Enter 发送 | Alt+Enter/Ctrl+J 换行 | Ctrl+C 中断 | /help
 > _                                                       ← 3~8 行 Composer
```

### 改动点（layout_manager.py）

1. **移除三层 Frame**：`_build_application()` 中 `Frame(...)` 全部改为直接 `Window(...)`。
   - 状态栏/body/composer 之间用 prompt_toolkit `Window` 渲染分隔线字符 `─`。

2. **状态栏重做**：
   - 新增 `build_header(server, project, phase, auto_review, checkpoint_count=0)` 签名，增加 `checkpoint_count` 参数。
   - 状态栏渲染为带背景色的单行 `FormattedText`（用 prompt_toolkit style，非 Rich ANSI），内容：
     `MoFox Code ● {phase_icon} {project} auto-review:{ON|OFF} cp:#N`
   - 使用 `Theme.status_bar_bg / status_bar_fg`。

3. **Body**：`Window(self._body_control, wrap_lines=False)` → `wrap_lines=True`（后续 phase 2 再按 block 类型区分）。

4. **Composer 多行输入**：
   - `_input_window` 高度从 `height=1` → `height=Dimension(min=3, max=8)`。
   - Buffer 初始化：
     ```python
     self._input_buffer = Buffer(
         history=InMemoryHistory(),
         completer=CommandCompleter(),
         complete_while_typing=False,
         enable_history_search=True,
         multiline=True,
     )
     ```
   - Enter 发送时**必须手动调 `append_to_history()`**：
     ```python
     @kb.add("enter")
     def _accept_input(event) -> None:
         text = self._input_buffer.text
         if text.strip():
             self._input_buffer.append_to_history()
         self._input_buffer.text = ""
         self._input_queue.put_nowait(text)
         self._invalidate()
     ```
   - **换行**使用 `Alt+Enter` 和 `Ctrl+J`（不用 Shift+Enter）：
     ```python
     @kb.add("escape", "enter")
     def _newline_alt_enter(event) -> None:
         event.current_buffer.insert_text("\n")

     @kb.add("c-j")
     def _newline_ctrl_j(event) -> None:
         event.current_buffer.insert_text("\n")
     ```

5. **Footer 简化**：只显示一行简短提示 `Enter 发送 | Alt+Enter/Ctrl+J 换行 | Ctrl+C 中断 | /help 帮助`。

## 二、输入历史 + Tab 命令补全

### 输入历史
- Buffer 已通过 `InMemoryHistory()` + `enable_history_search=True` + `multiline=True` 支持。
- `Up`/`Down` 默认走 prompt_toolkit 历史导航（与 PgUp/PgDn body 滚动不冲突）。

### Tab 补全（input_handler.py）
- 新增 `CommandCompleter` 类，实现 prompt_toolkit `Completer` 接口：
  ```python
  from prompt_toolkit.completion import Completer, Completion

  class CommandCompleter(Completer):
      COMMANDS = [
          "/exit", "/clear", "/undo", "/rollback", "/history",
          "/status", "/auto-review on", "/auto-review off",
          "/help", "/session", "/session resume", "/session delete",
      ]
      def get_completions(self, document, complete_event):
          text = document.text_before_cursor
          if text.startswith("/"):
              for cmd in self.COMMANDS:
                  if cmd.startswith(text):
                      yield Completion(cmd, start_position=-len(text))
  ```
- 在 `layout_manager.py` 中给 `_input_buffer` 挂上 `CommandCompleter()`。

## 三、Ctrl+C 智能中断

### 现状
Ctrl+C 无条件退出 TUI。

### 目标
- Agent **忙碌**时：发送 `user.interrupt`，不退出 TUI
- Agent **空闲**时：双击确认退出（2s 内第二次 Ctrl+C）

### 改动点

1. **layout_manager.py**：
   - `@kb.add("c-c")`：移除 `event.app.exit()`，只 `put_nowait(_INTERRUPT_SENTINEL)`。
     ```python
     @kb.add("c-c")
     def _interrupt(event) -> None:
         self._input_queue.put_nowait(_INTERRUPT_SENTINEL)
         # 不调用 event.app.exit()，由 app.py 决定是否退出
     ```

2. **app.py** `_input_loop()`：
   - 添加属性 `_last_ctrl_c_time: float = 0.0`
   - 捕获 `KeyboardInterrupt` 后：
     ```python
     except KeyboardInterrupt:
         if self._client.session.is_agent_busy:
             await self._client.send_interrupt()
             self._layout.append_body(
                 Text("  ⏸ 已发送中断信号", style=self._theme.warning)
             )
             continue
         now = time.monotonic()
         if now - self._last_ctrl_c_time < 2.0:
             raise  # 双击退出
         self._last_ctrl_c_time = now
         self._layout.append_body(
             Text("  再按一次 Ctrl+C 退出", style=self._theme.dim)
         )
         continue
     ```

## 四、审批 + 回滚不丢输入草稿

### 核心策略
**审批队列从空→非空时保存一次草稿，队列完全清空后恢复一次。**
rollback 同理，使用统一的草稿保存机制。

### 改动点

1. **layout_manager.py**：
   - 新增方法：
     ```python
     def save_input_draft(self) -> str:
         draft = self._input_buffer.text
         self._input_buffer.text = ""
         return draft

     def restore_input_draft(self, draft: str) -> None:
         if draft:
             self._input_buffer.text = draft
         self._invalidate()
     ```

2. **app.py** — 审批草稿：
   - 添加属性：
     ```python
     self._saved_input_draft: str | None = None
     self._handling_approval: bool = False
     ```
   - `_on_approval_request()` 逻辑：
     ```python
     async def _on_approval_request(self, payload: dict) -> None:
         was_empty = not self._approval_queue and not self._handling_approval
         self._approval_queue.append(payload)
         if was_empty and self._saved_input_draft is None:
             self._saved_input_draft = self._layout.save_input_draft()
         self._layout.request_input_refresh(clear_buffer=False)
         # ... 显示审批提示 ...
     ```
   - `_handle_pending_approval()` 结束时：
     ```python
     self._handling_approval = True
     try:
         # 处理审批...
     finally:
         self._handling_approval = False
         if not self._approval_queue and self._saved_input_draft is not None:
             self._layout.restore_input_draft(self._saved_input_draft)
             self._saved_input_draft = None
     ```

3. **app.py** — 回滚草稿（复用同一套机制）：
   - `_on_checkpoint_list_result()`：
     ```python
     async def _on_checkpoint_list_result(self, payload: dict) -> None:
         checkpoints_raw = payload.get("checkpoints", [])
         checkpoints = [CheckpointInfo(**cp) for cp in checkpoints_raw]
         self._pending_checkpoint_choice = checkpoints
         if self._saved_input_draft is None:
             self._saved_input_draft = self._layout.save_input_draft()
         self._layout.request_input_refresh(clear_buffer=False)
         self._input_handler.render_checkpoint_list(checkpoints)
     ```
   - rollback 完成后恢复：`self._layout.restore_input_draft(self._saved_input_draft); self._saved_input_draft = None`

## 五、回滚选择统一走 TUI 输入

### 现状
`_on_checkpoint_list_result()` 使用 `pause()` + `input()` + `resume()`。

### 目标
像审批队列一样，通过标志位在主输入循环中处理。

### 改动点（app.py）

1. 添加属性 `_pending_checkpoint_choice: list[CheckpointInfo] | None = None`

2. `_input_loop()` 中，在审批检查之后添加：
   ```python
   if self._pending_checkpoint_choice is not None:
       await self._handle_checkpoint_choice()
       continue
   ```

3. 新增 `_handle_checkpoint_choice()`：
   ```python
   async def _handle_checkpoint_choice(self) -> None:
       checkpoints = self._pending_checkpoint_choice
       self._pending_checkpoint_choice = None
       try:
           choice = await self._layout.get_input(" rollback(#|Enter 取消)> ")
       except (EOFError, KeyboardInterrupt):
           self._layout.restore_input_draft(self._saved_input_draft)
           self._saved_input_draft = None
           return
       choice = choice.strip()
       if choice.isdigit():
           step = int(choice)
           target = next((cp for cp in checkpoints if cp.step == step), None)
           if target:
               await self._client.request_rollback("to_id", target.id)
           else:
               self._layout.append_body(Text("  未找到该步骤", style=self._theme.dim))
       # 恢复草稿
       if self._saved_input_draft is not None:
           self._layout.restore_input_draft(self._saved_input_draft)
           self._saved_input_draft = None
   ```

4. 移除 `_on_checkpoint_list_result()` 中的 `pause()`/`input()`/`resume()` 逻辑。

## 六、Thinking 折叠：流式展开，结束后折叠

### 策略
- **流式输出期间**：Thinking 内容完整展开（保持现有 Panel 行为）
- **思考结束后**：自动折叠为 `🧠 Thinking (3.2s)` 单行摘要
- `_thinking_start_time` 在 `_on_agent_thinking()` 中兜底设置（因后端可能直接发 thinking 而跳过 status）

### 折叠时机（必须全部覆盖）
提取为专门方法 `_collapse_active_thinking_if_needed()`，在以下位置调用：

| 触发点 | 说明 |
|--------|------|
| `_on_tool_call()` 开头 | tool call 意味着 thinking 结束 |
| `_on_agent_text(is_final=True)` 末尾 | agent 回复完成 |
| `_on_agent_status(phase="ready")` | agent 回到就绪 |
| `_close_active_response_segment()` 中 source 切换时 | 不同 source 交替 |

### 改动点

1. **renderer.py**：
   - `build_thinking()` 保持不变（展开用）
   - 新增 `build_thinking_collapsed(duration_seconds: float) -> Text`：
     ```python
     def build_thinking_collapsed(self, duration_seconds: float) -> Text:
         return Text(
             f"  🧠 Thinking ({duration_seconds:.1f}s)",
             style=self._theme.dim,
         )
     ```

2. **app.py**：
   - 添加属性 `_thinking_start_time: float = 0.0`
   - `_on_agent_thinking()` 首行兜底：
     ```python
     if self._thinking_start_time == 0.0:
         self._thinking_start_time = time.monotonic()
     ```
   - `_on_agent_status(phase="thinking")` 时：记录 `self._thinking_start_time = time.monotonic()`
   - 新增 `_collapse_active_thinking_if_needed()`：
     ```python
     def _collapse_active_thinking_if_needed(self) -> None:
         if self._active_thinking_index is not None and self._thinking_start_time > 0:
             duration = time.monotonic() - self._thinking_start_time
             collapsed = self._renderer.build_thinking_collapsed(duration)
             self._layout.update_body_item(self._active_thinking_index, collapsed)
             self._active_thinking_index = None
             self._thinking_start_time = 0.0
     ```
   - 在 `_on_tool_call()` 开头、`_on_agent_text(is_final=True)` 末尾、`_on_agent_status(phase="ready")` 中、`_close_active_response_segment()` 中调用 `_collapse_active_thinking_if_needed()`。

## 七、Bash 输出保守折叠

### 策略（不要假设 exit_code 一定存在）
```text
exit_code == 0 且 stdout > 5行    → 折叠：显示前3行 + "...（共N行）"
exit_code != 0 且 exit_code 不为 None → 完整展开
exit_code is None                 → 保守：仅对 >20行 stdout 做截断
stderr                            → 默认不折叠，完整展示
```

### 改动点（renderer.py）

- `render_bash_output()` 新增参数 `exit_code: int | None = None`：
  ```python
  def render_bash_output(self, output: str, is_stderr: bool, exit_code: int | None = None) -> None:
      if is_stderr:
          # stderr 不折叠，完整显示（截断上限 100 行）
          ...
          return

      lines = output.splitlines()
      if exit_code == 0 and len(lines) > 5:
          collapsed = "\n".join(lines[:3])
          output = collapsed + f"\n... (共 {len(lines)} 行，已折叠)"
      elif exit_code is None and len(lines) > 20:
          output = "\n".join(lines[:10]) + f"\n... (共 {len(lines)} 行)"
      elif exit_code is not None and exit_code != 0:
          # 失败：完整展开（上限 80 行）
          ...
  ```

## 八、流式 Markdown 节流 + 去重

### 改动点（stream_renderer.py）

1. 添加属性：
   ```python
   self._last_emit_time: float = 0.0
   self._throttle_interval: float = 0.05  # 50ms
   self._dirty: bool = False
   self._last_emitted_content: str = ""
   ```

2. `_emit_markdown()` 末尾记录：
   ```python
   def _emit_markdown(self) -> None:
       if not self._content:
           return
       md = Markdown(self._content, style=self._theme.agent_text)
       if self._output:
           self._output(md)
       else:
           self._console.print(md)
       self._last_emitted_content = self._content
       self._last_emit_time = time.monotonic()
   ```

3. `feed()` 修改：
   ```python
   def feed(self, chunk: str) -> None:
       if not chunk:
           return
       # 累积内容（同前）
       if chunk.startswith(self._content):
           self._content = chunk
       else:
           self._content += chunk

       now = time.monotonic()
       # 第一块内容立即渲染，不等 50ms
       if self._last_emit_time == 0.0:
           self._emit_markdown()
           return

       if now - self._last_emit_time >= self._throttle_interval:
           self._emit_markdown()
           self._dirty = False
       else:
           self._dirty = True
   ```

4. `finalize()` 去重：
   ```python
   def finalize(self) -> None:
       if self._content and self._content != self._last_emitted_content:
           self._emit_markdown()
       self._dirty = False
   ```

## 九、`_refresh_header()` 统一封装

### 目的
避免各事件处理器散落 `build_header(...)` 调用，漏更新 checkpoint 数等。

### 改动点（app.py）

- 新增方法：
  ```python
  def _refresh_header(self, phase: str | None = None) -> None:
      session = self._client.session
      self._layout.build_header(
          server=self._config.server_url,
          project=session.project_name,
          phase=phase or session.phase,
          auto_review=session.auto_review_enabled,
          checkpoint_count=len(session.checkpoints),
      )
  ```
- 所有现有 `self._layout.build_header(...)` 调用点替换为 `self._refresh_header(phase=...)`。
