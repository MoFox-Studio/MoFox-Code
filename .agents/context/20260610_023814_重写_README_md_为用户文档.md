## README 内容大纲

### 1. 项目简介
- mofox-code 是 Neo-MoFox Coding Agent 的终端前端（TUI）
- Claude Code 风格的终端编程助手
- 通过 WebSocket 连接到 Coding Agent 后端

### 2. 功能特性
- 终端内交互式 AI 编程对话
- 流式 Markdown 实时渲染（代码块语法高亮）
- Bash 命令审批系统（含自动审查）
- Checkpoint 回滚机制（/undo, /rollback）
- 三套配色主题（dark / light / monokai）
- 配置文件 + CLI 参数分层配置

### 3. 环境要求
- Python >= 3.11
- 需要一个运行中的 Coding Agent 后端服务

### 4. 安装
```bash
git clone <repo_url> && cd mofox-code
pip install -e .
# 或
uv pip install -e .
```

### 5. 配置
配置文件：`~/.mofox-code/config.toml`
```toml
[server]
url = "ws://localhost:8765/coding-agent/ws"

[preferences]
theme = "dark"
auto_review = false
```

### 6. CLI 参数
| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--server` | 后端 WebSocket 地址 | `ws://localhost:8765/coding-agent/ws` |
| `--auto-review` | 启用自动审查 | false |
| `--theme` | 配色主题 (dark/light/monokai) | dark |
| `--project-dir` | 项目目录 | 当前目录 |
| `--verbose` | 详细调试 | false |

### 7. 内置命令
| 命令 | 功能 |
|------|------|
| `/exit` / `/quit` | 退出 |
| `/undo` | 回滚最后一步 |
| `/rollback` | 选择回滚到指定步骤 |
| `/history` | 查看操作历史 |
| `/status` | 查看当前状态 |
| `/auto-review on/off` | 切换自动审查 |
| `/clear` | 清屏 |
| `/help` | 显示帮助 |

### 8. 命令审批
当 Agent 需要执行 Bash 命令时，会弹出审批面板，提供五种选择：
- `a` 允许一次
- `s` 会话内允许该命令前缀
- `f` 永久允许该命令前缀
- `d` 拒绝
- `r` 开启自动审查模式
